The pattern
Add consecutive odd numbers starting from 1. After each addition you land on a perfect square. The nth ring has 2n−1 cells — exactly the nth odd number.

Algebraic proof
(n+1)² − n² = 2n+1. Each new square exceeds the previous by the next odd number — so stacking odds always produces squares.

The test
Subtract 1, 3, 5, 7… from your number. If you hit exactly 0, it's a perfect square. If you overshoot, it isn't.

Why it works
The sum 1+3+5+…+(2k−1) = k². If you reach 0 after k subtractions, the original number is k².
