Odd Numbers Build Squares

The sum of the first n odd numbers always equals n². Build the square visually, then test a number by subtracting consecutive odds yourself.

Watch the pattern: Each odd number (1, 3, 5, 7…) wraps around the previous square as an L-shaped ring. Add them up and you always land on a perfect square.
1 = 1²
Sum of first 1 odd number = 1
Why? Adding the (n+1)-th odd number, 2n+1, wraps a new top row and right column around the n×n square — exactly (n+1)² − n² = 2n+1 new cells. So each step produces the next perfect square.
Do the subtraction yourself. A number is a perfect square if and only if subtracting 1, 3, 5, 7… eventually reaches exactly 0. Each step you type the answer — the widget tells you if you're right.
