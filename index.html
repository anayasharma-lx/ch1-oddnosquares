Odd Numbers Build Squares
The sum of the first n odd numbers always equals n². Each new odd number adds a coloured L-shaped border — watch the square grow.
1 = 1²
Sum of first 1 odd number = 1
Why does this work? Each new odd number (2n−1) forms an L-shaped border — a top row and a right column — that wraps around the previous square. Adding 2n−1 cells to (n−1)² gives exactly n². 1 + 3 + 5 + … + (2n−1) = n²
Try:
If subtracting 1, 3, 5, 7… lands on exactly 0, it is a perfect square (we subtracted n odds, so it equals n²). If we overshoot 0, it is not.
